## 記入時の注意

- **概要**: 関連Issueがあれば `Closes #<番号>` を概要内に記載する。無い場合は無理に埋めず省略する。複数ある場合は行を複数に分ける。
- **変更ファイル**: `git diff --stat` 等を参照し、主要なファイルのみで構わない。
- **レビューしていただきたい設計判断**: 迷った点・意図的な方針が無ければセクションごと削除する。
- **動作確認**: 「確認済み」と「未確認」を実態に基づいて正直に分ける。確認できていないことを確認済みに含めない。
