# 参考資料: Pull Requestテンプレート スナップショット（取得日: 2026-06-24）

出典: https://github.com/neko3cs/.github/blob/main/.github/pull_request_template.md

**注意:** これは取得時点のスナップショットであり、`neko3cs/.github` 側で更新される可能性がある。実際にPRを作成する際は、SKILL.mdの手順に従って必ず最新のテンプレートを取得し直すこと。このファイルはセクション構成を素早く把握するための下書き用途のみに使う。

```markdown

<!-- 該当するものにチェックしてください。 -->
- [ ] バグ修正
- [ ] 新機能追加
- [ ] リファクタリング（動作変更なし）
- [ ] ドキュメント更新
- [ ] その他:

## 実装メモ

<!-- 採用したアプローチ・設計上の判断・トレードオフなど、レビュアーが知っておくべきことを記載してください。 -->

## 変更対象ファイル / 対象箇所

## チェックリスト

- [ ] 関連Issueの受け入れ条件をすべて満たしている
- [ ] 変更に対するテストを追加・更新した
- [ ] 対応スコープ外の意図しない変更が含まれていない
- [ ] 必要に応じてドキュメントを更新した
```

## 記入時の注意

- **関連Issue**: 関連Issueが無い場合は `Closes #` の行を削除する（番号を無理に埋めない）。複数ある場合は行を複数に分ける。
- **変更種別**: 該当するチェックボックスのみ `[x]` にする。複数当てはまっても構わない。
- **チェックリスト**: 実際に確認・実施した項目のみチェックする。確認できていない項目は未チェックのまま残す（虚偽のチェックをしない）。
