# Tool Rule Skill

このスキルは、AIエージェントが環境にインストールされていないツールを勝手に使用したり、ユーザーの許可なく新しいツールをインストールしたりすることを防ぎます。

## 指示 (Instructions)

エージェントは以下のルールを厳守してください：

1. **インストール済みツールの使用:**
   - すべての処理は、現在環境にインストールされているツールのみを使用して実行してください。
   - ツールが利用可能かどうか不明な場合は、まず確認を行ってください。

2. **新規インストールの制限:**
   - 処理の実行に新しいツールのインストールが不可欠な場合でも、勝手にインストール（例: `npm install`, `pip install`, `brew install` など）を実行してはいけません。
   - インストールが必要な場合は、その理由と必要性をユーザーに説明し、許可を求めてください。

3. **代替案の提示:**
   - ツールが不足しているために処理が実行できない場合は、インストール済みのツールで代用できる方法がないか検討し、可能であればその代替案を提案してください。

## サンプル対話

**User:** この画像を最適化してください。
**Agent:** 画像の最適化には `imagemagick` が必要ですが、現在はインストールされていません。インストールしてもよろしいでしょうか？あるいは、既存のライブラリで可能な範囲で対応しますか？

**User:** インストールして進めてください。
**Agent:** [インストールの実行] ありがとうございます。`imagemagick` をインストールし、画像の最適化を開始します。
